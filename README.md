# Akash Pathak - Portfolio Website

A clean, modern portfolio website for Akash Pathak, Infrastructure Engineer.

## Features

- **Dark Mode by Default** - Cappuccino-inspired color scheme with smooth theme toggle
- **Responsive Design** - Mobile-first approach for all screen sizes
- **Modern Tech Stack** - Built with Next.js 14, React 18, TypeScript, and Tailwind CSS
- **Smooth Animations** - Subtle transitions and hover effects
- **SEO Optimized** - Proper metadata and semantic HTML
- **Fast Performance** - Optimized images, code splitting, and lazy loading

## Color Palette

### Dark Mode (Default)
- Background: `#0f0f0f`
- Card: `#1a1a1a`
- Text: `#f5f1ed` (Cream)
- Accent: `#c89968` (Caramel)
- Muted: `#a8a8a8`

### Light Mode
- Background: `#faf8f5` (Cream)
- Card: `#ffffff`
- Text: `#1a1a1a`
- Accent: `#a0714f` (Darker Caramel)
- Muted: `#6b7280`

## Sections

1. **Navigation** - Sticky header with theme toggle and mobile menu
2. **Hero** - Striking introduction with CTAs
3. **About** - Professional background and interests
4. **Skills** - Technical expertise organized by category
5. **Projects** - Featured infrastructure projects with details
6. **Contact** - Contact form and social links
7. **Footer** - Copyright and credits

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.

## Deployment

Deploy to Vercel with one click:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/0prodigy/portfolio)

Or deploy manually:

```bash
npm run build
npm start
```

- **Framework**: Next.js 14
- **Language**: TypeScript
